# 2026-10-31 安全修复契约

此分支是 REC 的 v2board dev，不包含 FMPanel 的其他业务扩展。

- 邮箱恢复：数据库匹配后再次按应用层邮箱身份比较（ASCII 大小写兼容、域名 IDNA non-transitional，不折叠重音）；仅向保存的账户地址发码。恢复挑战绑定用途、用户 ID、邮箱与密码状态；旧普通验证码不能用于重置。注册仍用原验证码参数。
- 认证后的快速登录票绑定账户状态，改密/改邮箱后拒绝兑换；旧标量票需重新申请，URL/响应格式不变。不新增邮件登录。
- 会话：热缓存也检查 JWT 和服务端 session；改单会话同时清 JWT 缓存。管理员改密、角色和封禁变化在提交后撤销目标会话，长期登录不变。列表 auth_data 仅回显调用者当前凭据，其他会话为空字符串，仍按 session GUID 撤销。
- 开户：未填密码时逐账户生成 20 位随机密码，显式密码保持。单账号返回 `{data:true,credentials:{email,password}}`，批量返回含实际密码的 CSV，响应不缓存。随仓库旧后台分别下载 JSON/CSV；刷新后的后台使用新的静态资源版本。
- 支付：回调 method 必须匹配 UUID 所属配置类型；订单 payment_id 必须在锁内匹配所验证渠道；Epusdt 空密钥和非已支付事件拒绝。保留 GET/POST、回调应答和 REC 回跳 URL。
- 订单：同用户下单串行、锁内重查待支付/处理中订单。开通先锁用户与订单、重查 status=1，重复已完成任务不再加余额或开套餐。折算仅可原子认领本用户 status=3 来源；来源不匹配整笔回滚，报 `SURPLUS_ALREADY_CONSUMED`，不自动退款。优惠券个人限次包括待支付订单，仅取消释放个人名额。

验证不使用真实账户、付款或订单；生产 PHP CVE/运行时升级不在此次范围。

本地验证使用 REC 生产 composer.lock 重建的 80 个运行依赖（不更新生产 vendor），隔离 PHP 8.4、内存 SQLite 和内部网络 MariaDB。18 个定向用例 / 93 assertions 通过，包含真实用户行锁等待、重复折算/充值开通幂等、支付绑定、重音错配拒绝、两条快速登录签发路径和随机密码交付。旧后台 JS 语法与单个 JSON/批量 CSV 下载表达式检查通过；不等同于真实浏览器或支付上游验收。
